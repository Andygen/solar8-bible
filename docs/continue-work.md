# Продолжение работы над SOLAR 8 Bible

Это репозиторий сайта Bible, не игры. Сайт: https://andygen.github.io/solar8-bible/ . GitHub: Andygen/solar8-bible, ветка main, GitHub Pages. Пользователь общается по-русски, предпочитает выполнять согласованные изменения и публиковать их без повторных подтверждений.

## Текущее состояние

- Флот по планетам, отдельные досье персонажей, сценарий и поиск опубликованы.
- Развитие Player Interceptor: девять существующих ангарных изображений, накопленные улучшения и износ; восемь сцен Max добавлены как VO-черновики. Исходные 159 сцен и 457 реплик сохранены; дополнительно 24 предложенные реплики. Backup ROOK раскрывается после 8-1; Solar Crown после титров.
- Логотип владельца подчищен: `assets/solar-logo-polished.png`.
- На главной корабль заменён по референсу Player Interceptor. Последняя правка приглушает яркость и насыщенность, подгоняет освещение к исходной сцене: текущий фон `assets/helios-orbit-interceptor-lit.png`. Пользователь просил избегать мультяшного яркого корабля. История и промпты в `docs/hero-interceptor.md`.
- В Codex/VS Code пропало отображение сообщений, но агент продолжал работать. По просьбе пользователя временно добавлен попап на главной: `assets/temporary-update.js`, подключение в `index.html`. После восстановления чата предложить убрать попап; без запроса пока оставить. Это статический текст, не трансляция чата.

## Источники и сборка

Читайте `docs/media-expansion.md`, `docs/fleet.md`, `docs/ship-names.md`. Источники: `assets/fleet.json`, `assets/dossiers.json`, `assets/player-progression.json`. Статический сайт, HTML/CSS/JS, без npm-сборки.

Порядок при затрагивании всех разделов: `scripts/build-dossiers.py`, `scripts/build-upgrades.py`, `scripts/build-scenario.py`, `scripts/build-fleet.py`. Python + BeautifulSoup. В прошлой сессии был доступен переносной Python в `%TEMP%/solar8-python-313/python.exe`; при необходимости проверьте наличие. Не запускайте все генераторы ради мелкой CSS-правки.

После изменений проверять затронутые страницы, ссылки и мобильное отображение, коммитить и публиковать, проверять успешный Pages deployment. Не выдавать концепты и предлагаемые игровые эффекты за реализованные возможности игры.
