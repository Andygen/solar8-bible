SOLAR 8 — CAPTAIN ELIAS “STORM” NAVARRO
Семь отдельных вертикальных PNG для серии персонажей Bible: 2:3, тёмный графитовый фон.

СОСТАВ
navarro-waist-calm.png — исходный выбранный поясной образ.
navarro-front.png — анфас.
navarro-profile-left.png — нос направлен влево на изображении.
navarro-profile-right.png — нос направлен вправо.
navarro-full-body.png — полный рост спереди.
navarro-back.png — полный рост со спины.
navarro-waist-focused.png — сосредоточенный командир в напряжённой ситуации.

ОБРАЗ ПО АРТ-БРИФУ
Командир атмосферной станции Jupiter, 50–60 лет, сухой подвижный профессионал с обветренным лицом.
Тёмно-коричневая/графитовая атмосферная куртка поверх облегчённого pressure-suit, мягкие бежевые вставки, приглушённые янтарные индикаторы, маленький штормовой маркер на воротнике.
Спокойная опытная манера; без ковбойской стилизации.
Имя в библии остаётся рабочим.

ПРИМЕНЕНИЕ
Фон включён в PNG, как у существующих иллюстраций досье на Bible.
Базой образа считать спокойный поясной портрет; полный рост и вид со спины развивают конструкцию одежды.
Это художественные ракурсы, не точный чертёж для 3D. В профилях есть различия в размещении приборов и ремней; перед моделированием свести оборудование и швы в единый технический лист по базовому поясному портрету.
Диалоговые рамки, подписи, страница сайта и анимации не входят.
Оригинальные пиксели PNG сохранены без обработки. Размеры и режим — в technical-info.json.
Создано встроенным инструментом генерации изображений. Промпты шести новых изображений — в prompts.json; спокойный портрет взят из предыдущего шага.
