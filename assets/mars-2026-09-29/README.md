# Весь Марс: единый пакет для Bible

Состояние игры на 29.09.2026. Все пять миссий 4-1–4-5 реализованы. Этот архив заменяет необходимость переносить предыдущие отдельные пакеты Марса. APK и изменения других планет сюда не входят.

## Что внутри

- missions/: актуальные механики, звёзды, сюжетные связи и проверки каждой миссии.
- dialogues/mars-dialogues.json: **74 уникальных реплик RU/EN** всех пяти миссий, включая инструктажи и финалы. Из них 12 уже опубликованы, 62 ещё отсутствуют на сайте. Это единственный файл с записями для объединения; повторные pending-пакеты не нужны.
- dialogues/publication-status.json: какие ID уже были опубликованы при проверке, какие требуется добавить.
- dialogues/game-bindings.json: связи ID с игровыми файлами; review-ru-en.md — удобное чтение всех реплик.
- art/masters/: 10 оригиналов новой графики миссий, включая аватарку NOVA.
- art/runtime/: фактические оптимизированные изображения игры — фон, флот, объекты, NOVA, корабль игрока и ангарный вид Марса.
- assembler-animation-v1/: полный исходный набор Мегасборщика: 10 PNG, demo.html, JavaScript, pivots, manifest и контрольные суммы. Открыть demo.html для просмотра анимации. Старые цельные фазы не заменяются автоматически.
- screenshots/: примеры из игры. Скриншоты автоматических проверок, не запись обычного прохождения; таймеры и реплики на них могли быть переключены тестом.
- implementation-reference/: код миссий и перенос анимации для проверки фактических условий. Это выдержки, не самостоятельный игровой проект.

## Как обновить сайт

1. Прочитать CHAPTER-RU.md и описания missions/4-1.md … 4-5.md. Исправить состояние готовности, переходы и механику. Числа HP, таймеры и дополнительные звёзды — предложения игрового баланса, не утверждённый канон.
2. Объединить entries из dialogues/mars-dialogues.json с assets/dialogues.json **по стабильному id**. Существующие записи сохранить; при новых редакторских изменениях на сайте не затирать их локальной копией. Не подменять общий каталог этим файлом — здесь только Марс. Добавить NOVA в speakers и список разрешённых персонажей контракта.
3. Для канонических строк использовать story_id → data-dialogue-id; тексты брать из общего JSON. Инструктажи с gameplay_adaptation не выдавать за литературные сцены. Обновить revision и dialogue-contract.json, сверить привязки. Реплики 4-1 без story_id связывать вручную по сцене и говорящему, не по порядковому номеру ID.
4. Разместить новые изображения, оставляя названия сущностей из Bible. art/masters — оригиналы для приёмки, они могут весить больше 1 МБ; art/runtime — варианты, применённые в игре. Новая графика миссий ещё требует визуального утверждения. Публикация или наличие PNG не означает завершённую ручную проверку уровня.
5. Для сборки Мегасборщика разместить assembler-animation-v1 в отдельной папке вместе с demo.html; не смешивать её со старыми цельными фазами и прототипами. Координаты в rig-data.json относятся к исходным PNG, не к уменьшенным runtime-копиям.
6. После публикации игра подтянет мастер через tools/sync_dialogues.cjs --pull. Более поздние правки делать в опубликованном общем JSON.

## Актуальность и ограничения

Переходы в игре: 4-1 → 4-2 → 4-3 → 4-4 → 4-5 → меню. Сюжет указывает на Юпитер, но его миссии и предлагаемая новая механика турбин ещё не реализованы. Старые упоминания APK в заметке 4-1 относятся только к исторической сборке; APK со всеми пятью миссиями в этом архиве нет. Автоматические тесты пройдены, ручной баланс проверяем отдельно по одному уровню.

Референсы уже опубликованного флота в art/runtime даны для сверки, не как новые дизайны. Полная история проектной Bible остаётся на сайте; этот пакет объединяет все локальные материалы реализованной главы Марса.
